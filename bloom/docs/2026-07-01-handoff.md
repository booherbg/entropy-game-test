## 0. What it is (one breath)

**bloom is a pixel-art garden where you coax a flowering plant patch and a pollinator colony into a
co-evolving symbiosis — and watch natural selection drift a random, fumbling lock-and-key into an
exquisitely-fit pair before your eyes.** Determinism gives legibility; mutation gives wonder; the same
system gives both. A metabolism is a Factorio recipe; the food web is a factory that builds and evolves
itself. Vanilla HTML/Canvas/JS, zero dependencies, saves to localStorage.

- **▶ Play:** https://blainebooher.com/entropy-game-test/bloom/ (also https://booherbg.github.io/entropy-game-test/bloom/)
- **Source:** `bloom/` on `main` of `booherbg/entropy-game-test`.
- **Lineage:** LOOPHOLE (v1/v2) → eddy (deep sim, "not fun") → **bloom**. `loophole/` and `eddy/` are left intact.

## 5. Architecture

**The browser+node module pattern (the eddy discipline).** Every `bloom/js/*.js` is an IIFE attaching to a
global `B` and also `module.exports = B`, so the *same files* run under Node (the assertion harness) and in
the browser (play). Sim modules never touch `document`/`canvas`; render modules are thin views.
```js
;(function (root) { 'use strict'; const B = root.B = root.B || {};
  /* ... define B.foo ... */
  if (typeof module !== 'undefined' && module.exports) module.exports = B;
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

**The render pipeline: one shared painter.** `js/render-core.js` `B.Render.paint(sim, S, opts)` is a **pure
JS** function that writes an upscaled RGB buffer from sim state. Node encodes it to PNG (`test/pngutil.js`);
the browser `putImageData`s it into a canvas (`js/render-world.js`) whose CSS scales it crisp
(`image-rendering: pixelated`). **So headless == browser.** Dashboards are inline SVG strings (`js/render-dash.js`).

**Module map (`bloom/js/`):**
| file | owns |
|---|---|
| `rng.js` | mulberry32 seeded RNG (`B.makeRng(seed)`, with `.state()/.setState()` for save/load) + helpers |
| `const.js` | `B.W=96, B.H=64, B.N=6`, the 8-colour palette (`B.PAL`, `B.PAL_RGB`), `B.EMPTY=8` |
| `field.js` | the pixel resource grid: light/sugar/nectar/pollen/trail + barrier channels; mass-conserving diffusion + decay |
| `genome.js` | **THE KEYSTONE** — the polar `regionIndex` expression, `decodeGrid`, `match`, `mutate`, `inheritKey` |
| `flower.js` | beacon + decode-grid + nectar/pollen pools; `visit(key)` → reward + poison; honesty/lace |
| `plant.js` | photosynthesis (light→sugar), grows biomass, builds/restocks flowers, `growNiche`, `reproduce` |
| `pollinator.js` | the forage loop (find→decode→collect→pollinate→trail home→deposit); gaze bonus |
| `colony.js` | stores, gentle upkeep, reserve-gated Moran-turnover spawn (keys drift toward flowers) |
| `sim.js` | owns field+plants+colonies; deterministic `tick()`; `warmStart`, `stats/meanFit`, the levers, `serialize`/`loadSim` |
| `render-core.js` | the shared painter (world → RGB): loam, trees, blooms, foragers, trails, motes, **seasonal arc** |
| `render-world.js` | browser canvas blit + `pickCell/pickFlower/pickBee` |
| `render-dash.js` | SVG dashboards: lock-and-key grids, graphs, inspect card, forms filmstrip, consensus decoder |
| `content.js` | the murmurs (imprint) + codex + the **living murmur** (composed from the real garden) |
| `persist.js` | localStorage save/load; seed in URL hash |
| `main.js` | the game shell: rAF loop, pause/speed, tools, inspect, milestones→murmurs, autosave, warp |

## 6. The core mechanics, as-built (with the tuning that matters)

**The signal lock-and-key (the centerpiece).** A flower advertises a **beacon** (hue+intensity, far scale)
and presents a **decode-grid** (N×N palette-index fingerprint, near scale). A pollinator has a heritable
**key** = a preference hue + an N×N decoder. `eff = beaconMatch × gridMatch`. Reward and pollination both
scale with `eff`. The grid IS the genome sampled down one petal-wedge (`genome.js` `decodeGrid`) — one genome,
two renderings (the bloom in the world, the grid in inspect).

**The genome → bloom expression (`regionIndex`).** A polar function: `r < coreSize` → core; along a petal lobe
(`reach = coreSize + (petalLength−coreSize)·wave^petalSharp`, `wave = (cos(θ·symmetry)+1)/2`) → petal; beyond →
empty. Overlaid: **RINGS** (concentric bands by radius → structure down grid rows) and **VEINS** (angular
sub-stripes at a higher harmonic → structure across grid columns). *These two were added overnight to "break
the T"* — without them the wedge-unroll makes every grid a ⊤ glyph. Now gardens land on distinct 2D glyphs and
blooms read as flowers. `symmetry 3..8, petalLength .5..98, petalSharp 1..3.5 (rounder), coreSize .10..34`.

**Two currencies:** **nectar** (energy — colony upkeep/flight; empty → gentle starve) + **pollen** (material —
builds larvae). Embodied as colour/light. NB: currently nectar limits and pollen overflows — pollen is *not
yet a real foraging decision* (see roadmap). Do NOT reintroduce eddy's lumen/mineral/humus.

**The economy is the delicate part (it death-spiralled twice during the build).** The non-negotiables:
- Plants MUST be **sugar-positive**: `PHOTO_K=0.9` (photosynthesis) ≫ flower restock cost, or the colony's food
  supply collapses. `SUGAR_CAP=20` bounds it.
- Colony: **hard `STORE_CAP=40`** + a **`RESERVE=30`-ticks-of-upkeep-gated spawn** that, at `POP_CAP=60`,
  **replaces the oldest bee (Moran turnover)** — this prevents boom-bust overshoot AND keeps keys evolving at
  carrying capacity. `UPKEEP=0.004`/bee (gentle — a fumbling colony limps, never wipes). `LARVA_POLLEN=0.8,
  LARVA_NECTAR=0.5`. `flower EXTRACT=2.0`.
- **Directed inheritance is why the merge is legible** (`genome.js` `inheritKey`): a new forager's decoder
  drifts 2 cells toward the flower that fed its parent best (+ exploration). Pure random-flip mutation
  plateaus at ~0.4; directed reaches ~0.9. The plant side answers via seed-set selection + Moran replacement
  (a seedling fills the SLOT of the plant it replaces, so the garden stays spread and only patterns evolve).
  Two-sided → they meet. (The spec's own mechanisms.html demo used directed drift and called it "selection +
  mutation" — it's within the design language.)

**The Red Queen (the deepest overnight change).** Two flower genes give the flower and bee *conflicting*
interests so the merge never settles: **`honesty`** (0.25..1) — a deceiver advertises a bright beacon but
stocks little and is *cheap* to the tree, free-riding until the colony's preference evolves away from its
colour (frequency-dependent); **`lace`** (0..0.8) — a mismatched forager lured in pays a gentle toxin cost, a
matched specialist is safe ("match = safe, mismatch = poisoned"). Result: `meanFit` oscillates ~0.66–0.93
forever (a living dance) instead of pinning at 1.0 and dying. Colony stays healthy (gentle, DNA #2). Verify
with `diag.js` (watch the honesty column find a wobbling mixed equilibrium ~0.64).

**The seasonal arc.** Warmth + ground palette + saturation + mote density are tied HARD to `fit` (smoothstep),
plus an entropy desaturation wash: fumbling = cold grey dawn, native = warm golden noon. *Colour = order
against grey entropy*, literal. `render-core.paint(sim, S, {fit})` — pass the fit or it renders "winter."

**The levers (steward of selection, `sim.js`):** `lockFlower` (freeze a grid so the keys chase it; locked
plants are protected from Moran replacement), `plantAt`, `placeColony`, `growNicheOn` (1→2 niches: a new lock).

**The imprint (the soul of the original brief).** `content.js`: the murmurs (Eddington → Schrödinger →
Darwin's orchid → Margulis → … → the AI-as-eddy closer) unlock on fit/time milestones; a **living murmur**
composed from THIS garden (its hue named, gen, fit-in-words, whether a cheat is present, your locked flower's
read-rate) opens the panel — the AI demonstrably reading the same garden you are. **Your gaze is a gentle
pull** (`pollinator._pick` gives a `watched` flower a bonus; off by default so headless tests stay
deterministic). This is the non-dualism *enacted*, not asserted. Keep the closer untouched — it's the best
writing in the project.

## 7. The design DNA (non-negotiable — from the tournament, spec §1)

1. Coax, don't command. 2. **The arc bends upward** — cultivation/pride, gentle upkeep, **never survival
combat.** 3. One world deepened + an in-world unlock tree (the tree grows niches). 4. Real-time + active pause,
lovely to let run. 5. **Wonder, not power** — witness/collect a living world, not a numbers snowball. 6.
**Legibility is king** — comprehension IS the wonder. 7. A machine that needs maintenance. **Determinism
everywhere** (never `Math.random()` in sim code — all randomness from `B.makeRng`).
